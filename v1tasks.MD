Rooms: create a room, join by code or link, a live player list, the host starting the game, and no accounts.

Round engine, run by the server: the five phases (lobby, role reveal, hints, vote, result), phase timers, turn order, vote tallying, and sending each player only their own role. The secret word never reaches a phone except as that player’s own card.

Hints: a one-word text input on your turn. The server rejects hints that contain the secret word, and skips your turn if the timer runs out.

Packs: about 6 built-in packs of 40-60 words each, such as Food, Places, Cricket and Bollywood. Store a decoy with each word now, so the related-word mode can be added later without redoing the data. The host picks a pack before starting.

Results screen: the impostor, the word, all hints, vote counts, a simple score, and a “play again” button.

Resilience: a player who refreshes can rejoin as themselves (keep a token in the browser). If the host leaves, host passes to someone else. Anyone joining mid-round waits for the next one. Empty rooms are deleted after a while.
